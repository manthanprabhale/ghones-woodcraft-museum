# Ghone’s WoodCraft Museum — website prototype

A responsive React + Vite museum website using the approved heritage-luxury direction: forest green, antique gold, walnut brown, warm ivory, editorial photography, a dedicated filtered gallery, full-screen artwork viewer, artist story, location link, and WhatsApp enquiry links.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the VS Code terminal run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.
5. Test a production build with `npm run build`.
